# geodev-lab-project

Which built-up areas of Lokoja LGA are repeatedly affected by flooding,
and how many buildings, people and critical infrastructure are
potentially exposed?

A geospatial flood monitoring and exposure assessment project for
Lokoja LGA, Kogi State, Nigeria, using satellite imagery, elevation,
rainfall, population and OpenStreetMap data.

Built over twelve months with GeoDev Lab Africa, Cohort One.
See project-brief.md for the full brief.
